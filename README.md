# DeutschDrill

German vocabulary and grammar drilling app. Fast, focused, keyboard-first.

**Live**: https://ben-koshishek.github.io/deutsch-drill/

## Stack

React 19, TypeScript, Vite, Tailwind CSS v4, Mantine UI, Dexie (IndexedDB)

## Development

```bash
pnpm dev      # Start dev server (http://localhost:5000)
pnpm build    # TypeScript check + production build
pnpm lint     # Run ESLint
pnpm test     # Run Vitest in watch mode
pnpm test:run # Run Vitest once (CI)
pnpm preview  # Preview production build
```
